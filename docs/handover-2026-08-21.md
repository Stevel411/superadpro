## 1. BANNER ADS — new product (the headline build)

A second ad format alongside video campaigns, **bundled with campaign packs**. Members place image or HTML banners that run on an internal showcase **and** a public, SEO-built directory that pulls external organic traffic over time.

### Model (locked with Steve)
- **Bundled with packs**, not sold separately. Owning an active pack unlocks **banner slots = `videos_allowed_for_level`** (2 for <$100, 4 for $100–$400, 6 for $600+) — mirrors video slots exactly, counted separately.
- **Impressions + clicks count toward the pack's delivery total**, alongside video views (Steve's call — banners "do the same thing"). Impression fires when a banner is ≥50% visible for 1s; click tracked on the outbound tap.
- **Image upload OR pasted HTML/embed code.** HTML runs **sandboxed in an iframe** (no same-origin) so third-party code can't touch the page.
- **Moderation = auto-approve + report→removal**, plus a strobing auto-flag. 3+ open reports auto-hides a banner pending review.
- **16 IAB sizes** grouped (Horizontal / Rectangle & Square / Vertical / Mobile). Animation (GIF + HTML5) welcome; **rapid strobing >3 flashes/sec is auto-flagged** (WCAG seizure-safety) — real GIF brightness-swing detection via Pillow.

### Schema (`app/database.py`)
- **`BannerAd`** (table `al_banner_ads`) and **`BannerReport`** (table `al_banner_reports`).
- **CRITICAL NAME COLLISION (fixed):** SuperAdPro already had a `banner_ads` table (different schema: title/slug/link_url/keywords/is_featured), created on an earlier deploy. My `CREATE TABLE IF NOT EXISTS banner_ads` was a silent no-op against the existing table, so my columns (`pack_purchase_id`, `mode`, `html_code`…) never applied → every ORM query 500'd. **Fix: renamed AL's tables to `al_banner_ads` / `al_banner_reports`** (models, CREATE statements, FK, and all raw SQL in `main.py`). SuperAdPro's table left untouched. (`c1034c9db`)
- `banner_slots_for_level()` mirrors `videos_allowed_for_level`. Tables auto-create on deploy via `CREATE TABLE IF NOT EXISTS` in `run_migrations()`.

### Backend APIs (`app/main.py`)
- `POST /api/al/banner/upload-image` — R2 upload via `upload_image(...)` from `app.r2_storage`; GIFs kept animated; `_gif_strobes()` brightness-swing strobe check.
- `POST /api/al/banner/create` — `_banner_slot_for_user()` picks the highest pack with a free banner slot; image or HTML mode; strobing GIFs held `status='flagged'`.
- `GET /api/al/banners/showcase` — live banners + categories.
- `GET /api/al/banners/mine` — member's banners + per-pack slot usage + totals/CTR (drives the dashboard card).
- `POST /api/al/banner/{id}/impression` — denormalised counter (active only).
- `GET /api/al/banner/{id}/click` — count + 302 to destination.
- `POST /api/al/banner/{id}/report` — the removal path.
- Banner impressions rolled into pack aggregate in `/api/al/pack-performance` (exposes `banner_views`/`banner_count`). Analytics hero copy softened from "verified 30-second watch" to "real views and banner impressions" so it stays honest.

## 3. KEY LEARNINGS (this session)
1. **Table-name collisions with SuperAdPro's shared codebase are real.** SAP already had `banner_ads`; `CREATE TABLE IF NOT EXISTS` silently no-op'd against it. **Prefix AL-only tables with `al_`** and check for an existing table name before adding one.
2. **New ORM models MUST be imported into `main.py`** (`from .database import BannerAd, BannerReport`) or every query throws `NameError` → 500. (Cost a debug cycle — `902822a72`.)
3. **Public SEO pages = server-rendered HTML, not React SPA.** Crawlers need the content in the HTML. The `_discover_shell` pattern (title/meta/OG/JSON-LD + inline tracking JS) is the template for any future SEO surface.
4. **Sandbox egress is HTTP(S) 443/80 only** — cannot reach Postgres ports (26110, 10638) directly. For DB work on a decommissioned/offline app, use the app's own **R2 backup** system (Cloudflare, survives Railway deletion) rather than a direct connection.
5. **Railway "Limited Access — deploys paused (upstream issue)" is a real incident state.** Deploys queue and won't land; re-triggering just stacks the queue. Wait it out — don't push more. (Cost ~15 min mid-session; cleared on its own.)
6. **`pack_purchase_id` on `video_campaigns` is still raw-SQL-only** (not on the ORM model) — carried over, still bites.
